# Documentation

This directory contains standards shared by all projects in Znect All Plugins.

- [Plugin standard](PLUGIN_STANDARD.md) — required folder contents and metadata.
- [Plugin lifecycle](PLUGIN_LIFECYCLE.md) — maturity statuses, versioning, and promotion criteria.
- [Security policy](SECURITY.md) — secrets, permissions, dependencies, and vulnerability handling.

Plugin-specific installation, usage, API, and troubleshooting instructions belong in that plugin's own folder.
